DEPLOYMENT NO GITHUB PAGES

Este site foi construído em um arquivo único (`index.html`), ideal para hospedagem imediata e gratuita no GitHub Pages.

Passo a passo rápido:

  1. Crie um repositório público no GitHub (ex: cyber-dump-search).
  2. Crie um arquivo chamado index.html na raiz do repositório.
  3. Cole todo este código HTML gerado e faça o commit.
  4. Vá em Settings > Pages no seu repositório.
  5. Em Build and deployment, escolha a branch main e pasta / (root).
  6. Salve e acesse seu site no link gerado pelo GitHub!
